What each variant is for

A keeps a running history of prompts next to the frame, so you can build a sequence board by board and see what Claude placed each time. It takes 320px from the camera view.

B floats over the camera view and opens from the Prompt button or a shortcut (to be picked so it doesn't clash with the Shot Generator's own keys). The frame stays full size; only the last result shows.

Both do the same thing underneath: your text plus the current scene goes to Claude, Claude returns a scene, and the Shot Generator loads it. Save to Board stays the existing button.
